Campus Marketplace — Express API Demo

This local evaluation page demonstrates Node.js + Express, JavaScript fetch, JSON file persistence and full CRUD. The marketplace itself uses Supabase Auth/PostgreSQL for production data. This demo is intentionally not included in Cloudflare deployment.

Live endpoints: GET /api/feedback, POST /api/feedback, PATCH /api/feedback/:id, DELETE /api/feedback/:id.
